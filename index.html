About this explorer

This map displays residential tax lots in Manhattan and recorded rent-stabilized unit counts from 2008 through 2025. Use the time slider to see how each lot’s classification changes over time.

Data note: rent-stabilized unit counts are based on the project dataset and should be interpreted alongside its methodology and limitations.
